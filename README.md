# Gestor de Pedidos e Inventario 📦⚽

Una aplicación web de gestión de inventario y ventas diseñada para controlar pedidos de camisetas de fútbol en tiempo real. Enfocada en la resolución de problemas lógicos de negocio, manipulación eficiente del DOM y creación de interfaces funcionales e intuitivas.

🔗 **Demo en vivo:** [gestor-pedidos-ucqt.vercel.app](https://gestor-pedidos-ucqt.vercel.app)

---

## 🚀 Características Principales

- **Registro de Ventas (CRUD):** Creación, visualización y gestión de nuevos pedidos en tiempo real.
- **Gestión Dinámica de Stock:** Cálculo automatizado del volumen de camisetas requeridas desglosado por talla (S, M, L, XL).
- **Control de Pagos:** Monitoreo visual de pedidos pagados frente a cobros pendientes.
- **Eliminación y Limpieza:** Posibilidad de cancelar o eliminar registros erróneos, sincronizando el inventario al instante.

---

## 💻 Tecnologías Utilizadas

- **Frontend:** HTML5 semántico, CSS3 (Diseño responsive, Flexbox, variables de estado).
- **Lógica de Negocio:** JavaScript (Manipulación del DOM, gestión de arrays y objetos, renderizado dinámico y eventos).
- **Despliegue:** Vercel (CI/CD continuo).

---

## 🧠 Aprendizajes Técnicos Clave

Durante el desarrollo de esta aplicación se consolidaron principios fundamentales:
1. Conexión directa entre la interfaz de usuario (UI) y estructuras de datos dinámicas en memoria.
2. Renderizado dinámico y actualización eficiente de nodos en el DOM.
3. Control y persistencia del estado en la sesión mediante captura y prevención de eventos (`event.preventDefault()`).
